---
title: "How to Build an Actual vs. Goal Report  "
---

## Overview

Performance Reports allow you to display actual performance alongside client goals and targets in a single table. This makes it easy to monitor pacing across metrics such as **Ad Spend, Revenue, CPA, nCAC, and MER** without manually calculating variance in a spreadsheet.

> **Before You Begin: Have you created your Goal Metrics?**
>
> Before building an Actual vs. Goal report, you'll need to create the Goal Metrics you want to track and tie each one to its corresponding actual performance metric.
>
> If you haven't created your Goal Metrics yet, start with **How to Create a Goal Metric** before continuing with this guide.

## Step 1: Create Your Performance Report

1. From the left navigation menu, expand **Performance Reports** and click **Create New Report**.
2. Select **From Scratch**.
3. Enter a **Title** and **Description** for your report.

Under **Data Source Categories**, select all categories needed for your report. For a typical multi-channel Actual vs. Goal report, this will include:

- **Commerce** for Shopify data
- **Media** for paid media data

Next, select Shopify and any paid media platforms you want included in the report.

Configure your preferred **Group By**, **Visibility Level**, and **Default Date Range**.

## Step 2: Add Your Goal Metrics

Under **Metrics**, locate the **Custom** metrics section and select the Goal Metrics you want to include in your report.

When a Goal Metric is created, it is already tied to its corresponding actual performance metric in SuperOrbital. Because of this, **you do not need to separately add both the actual metric and the Goal Metric to your report**.

For example:

- Select **Meta Budget** to display Meta Budget alongside actual Meta Ad Spend.
- Select **Revenue Goal** to display your Revenue Goal alongside actual Shopify Revenue.
- Select **nCAC Goal** to display your target alongside actual nCAC.
- Select **MER Goal** to display your target alongside actual MER.

When the report is created, SuperOrbital will automatically display the corresponding **Actual** value alongside your **Goal** value. If **Show Variance %** was enabled when the Goal Metric was created, the report will also automatically include the percentage variance between Actual and Goal.

Once you've selected all of the Goal Metrics you want to track, click **Create Report**.

## Step 3: Review or Update Your Goals

Once your report has been created, use the date range picker to select the period you want to review.

If you need to add or update target values:

1. Click **Set Goals** at the top of the report.
2. Enter or update the daily target values for one or multiple Goal Metrics.
3. Click **Save Goals**.

Your Performance Report will now display actual performance alongside your goals and variance, giving you a single view for monitoring performance against plan.
