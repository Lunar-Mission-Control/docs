## Overview

**Summary Dashboards** provide standardized, ready-to-use views of your client's Shopify and paid media performance. These dashboards are automatically populated using the data sources connected to the client's SuperOrbital workspace, giving you immediate access to key business and channel-level KPIs without requiring any report configuration.

Summary Dashboards are designed for quick performance monitoring and analysis, while **Custom Performance Reports** and **Custom Dashboards** can be used when you need more specialized or granular reporting.

## Executive Summary Dashboard

The **Executive Summary Dashboard** combines Shopify sales and order data with paid media performance in a single view.

Use this dashboard to monitor overall business performance and holistic KPIs such as **Revenue, Total Ad Spend, MER, CAC, and AOV**.

The Executive Summary is primarily standardized, but the scorecards at the top of the page can be customized to reflect the KPIs most relevant to each client.

## Channel Performance Dashboards

SuperOrbital provides a separate **Channel Performance Dashboard** for each supported paid media platform connected to the client's workspace.

These dashboards provide a standardized view of platform-level performance, including:

- Primary paid media KPI scorecards
- Performance trends and period-over-period comparisons
- Performance by Day, Week, Month, or Year
- Campaign-level performance

While each dashboard follows the same layout and functionality, the data displayed reflects the individual paid media platform you're viewing.

## When to Use Custom Reporting

Summary Dashboards are designed to provide quick access to the most commonly used performance views.

When you need reporting that goes beyond these standardized dashboards, use **Custom Performance Reports** or **Custom Dashboards** to create more tailored views using custom metrics, filters, dimensions, goals, or additional data sources.
