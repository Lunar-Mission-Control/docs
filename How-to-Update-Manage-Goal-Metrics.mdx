## **Overview**

After creating a Goal Metric, you'll need to enter the target values you want to track against. SuperOrbital provides two ways to add or update these values, and you can use whichever method works best for your workflow.

You can update Goal Metric values directly from the **Manage Goals** page, which also supports bulk updates using an XLSX template, or you can update goals directly from an existing **Performance Report**.

Before getting started, you'll need to create your Goal Metric. If you haven't already done so, see **Manage Goals | How to Create a Goal or Target Metric**.

## **Option 1: Update Goals from Manage Goals**

### **Step 1: Select Your Goal Date Range**

1. From the left navigation menu, expand **Performance Reports** and select **Manage Goals**.
2. Select the appropriate **Range**:
   - Weekly
   - Monthly
   - Quarterly
   - Yearly

The Range determines the end date of the period you're updating. For example, if you're entering goals for a single month, select **Monthly**. If you're entering goals for the entire year, select **Yearly**.

3. Select your **Start Date**.

For example, if you're entering goals for August, select **August 1**. With **Monthly** selected as your Range, your selected date range will include August 1 through August 31.

### **Step 2: Select Your Goal Metric**

1. Select the **Category** and **Data Source** associated with the Goal Metric you previously created.

For example, if you're updating a **Meta Budget** goal:

- **Category:** Media
- **Source:** Meta Ads

2. Once you've selected your Category and Source, any Goal Metrics created using the **Custom User Metric** entry type for that data source will become available.

**Note:** If you don't see the Goal Metric you're looking for, confirm that you've already created it as a Custom User Metric. See **Manage Goals | How to Create a Goal or Target Metric** for instructions.

3. Select the Goal Metric you want to update.

A table will appear below with a row for each date in your selected range and empty cells where you can enter your target values.

### **Step 3: Enter Your Goal Values**

You can update your daily Goal Metric values in one of two ways:

- **Enter values directly** into each daily row of the table.
- **Use the XLSX template** to update goals in bulk. Download the template, enter your goal values, and re-upload the completed file using the options at the top of the table.

Once all Goal Metric values have been entered or uploaded, click **Save**.

## **Option 2: Update Goals from a Performance Report**

You can also update Goal Metric values directly from a Performance Report. This is especially useful when you're already reviewing a Daily/Monthly Tracker or another report that includes your goals.

### **Step 1: Add the Goal Metric to Your Report**

Start by either editing an existing Performance Report or creating a new Performance Report from scratch.

As long as the report includes the **Category** and **Data Source** associated with your Goal Metric, the metric will be available under **Metrics \> Custom**.

1. Select the Goal Metric you want to include.
2. If you're editing an existing report, click **Update Report**.
3. If you're creating a new report, click **Create Report**.

### **Step 2: Set Your Goal Values**

Once you're viewing the Performance Report:

1. Use the date range picker to select the period you want to update.
2. Click **Set Goals** at the top of the page.
3. A pop-up will appear where you can enter or update the daily target values for your Goal Metrics.

You can update one or multiple Goal Metrics from this view.

4. Once you've entered your target values, click **Save Goals**.

Your updated Goal Metric values will now appear directly within your Performance Report table alongside the corresponding actual performance metrics.
