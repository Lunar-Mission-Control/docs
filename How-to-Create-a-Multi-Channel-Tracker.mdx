title: "How to Create a Multi-Channel Tracker"
---

## Overview

Performance Reports allow you to build fully customizable reporting tables using data from any connected data source in SuperOrbital. You can combine Shopify, GA4, and paid media platform metrics into a single report without writing formulas or manually joining data in Excel.

Performance Reports also support custom metrics and client goals, making them an ideal solution for building Daily or Monthly Trackers that compare actual performance against business targets across multiple marketing channels.

## Step 1: Create a New Performance Report

1. From the left navigation menu, expand **Performance Reports**.
2. Click **Create New Report**.
3. Choose one of the following options:
   - **From Existing** – Start with a SuperOrbital template or use an existing Performance Report as your starting point.
   - **From Scratch** – Build a new Performance Report from the ground up.

For a Daily/Monthly Tracker, select **From Scratch**.

4. Enter a **Title** and **Description** for your report.

## Step 2: Configure the Report

### Select Your Data Sources

1. Under **Data Source Categories**, select:
   - **Commerce**
   - **Media**
2. Under **Data Sources**, select:
   - **Shopify**
   - Every paid media platform connected to the client's SuperOrbital workspace that you want included in the report.

### Configure the Report Settings

Under the **Configurations** section, configure the following settings:

#### Group By

Choose how the report will be grouped by default.

For a Daily/Monthly Tracker, select either:

- **Daily**
- **Monthly**

> **Note:** After the report has been created, users can dynamically switch between Daily, Weekly, Monthly, and Quarterly views, so this setting simply determines the report's default view.

#### Dimension & Attributes

Leave **Dimension** and **Attributes** blank for Daily/Monthly Trackers.

These settings are primarily used for single-source Performance Reports that group data by dimensions such as Campaign, Ad Set, Product, or Sales Channel.

#### Visibility Level

Choose who should have access to this report.

- **Personal Reports** – Visible only to you.
- **All Lunar Users** – Visible only to Lunar employees.
- **All Users** – Visible to everyone with access to the client's SuperOrbital workspace, including both client users and Lunar employees.

#### Default Date Range

Select the default rolling date range for the report.

This determines which date range is displayed each time the report is opened. Users can still change the date range at any time using the report's date picker.

## Step 3: Select Your Metrics

The **Metrics** section allows you to add any supported platform metric from the data sources you selected during configuration. You can also include any custom metrics associated with those data sources.

For a typical Daily/Monthly Tracker, consider including:

- Shopify Revenue
- Shopify New Customer Revenue
- Shopify Returning Revenue %
- Shopify Orders
- Shopify New Customer Orders
- Total Ad Spend
- nCAC
- CAC
- MER

> **Important:** Before selecting your Shopify Revenue metric, confirm which revenue definition your client uses. Some clients report on **Total Sales**, while others use **Net Sales** or **Gross Sales**. If the client excludes sales channels such as Wholesale, Point of Sale, or TikTok Shop, you may first need to create a custom filtered metric. See **How to Create a Filtered Metric** for step-by-step instructions.

Once you've selected all of your metrics, click **Create Report** to generate your Daily/Monthly Tracker.
