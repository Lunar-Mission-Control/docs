## Overview

Performance Reports allow you to build fully customizable reporting tables using data from across SuperOrbital. Unlike standardized dashboards, Performance Reports give you control over the data sources, metrics, date groupings, and reporting structure included in each report.

You can combine data from **Shopify, GA4, paid media platforms, and custom Google Sheet data sources** into a single table without writing code or manually joining data in spreadsheets.

Performance Reports also support **Custom Metrics and Goals**, giving you the flexibility to build reporting around the specific KPIs and targets that matter to each client.

## What Can You Build?

Performance Reports can be configured for a variety of reporting needs, including:

- Multi-channel Daily, Weekly, Monthly, or Quarterly Trackers
- Actual vs. Goal performance reporting
- Campaign-level performance reports
- Platform-specific reporting
- Custom reporting using filtered or calculated metrics
- Reporting that incorporates custom data sources connected through Google Sheets

Because reports can combine multiple data sources and custom metrics, they can replace many reporting workflows that would otherwise require manually joining data or maintaining formulas in Google Sheets.

## Customize Reporting for Each Client

Every client measures performance differently. Performance Reports allow you to customize reporting around those differences while continuing to use data automatically synced into SuperOrbital.

You can incorporate **Custom Metrics** to filter or calculate client-specific KPIs, add **Goals** to track actual performance against targets, and connect **Custom Google Sheets** when the data you need isn't available through a native SuperOrbital integration.
