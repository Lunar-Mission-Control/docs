## **Overview**

Goals in SuperOrbital allow you to define client-specific targets and track actual performance against those targets using the data SuperOrbital automatically pulls from connected platforms.

Goals are created as **Custom User Metrics** and can be tied to any supported standard or custom metric in SuperOrbital. This gives you the flexibility to set targets for both standard platform KPIs and metrics that have been customized specifically for your client's reporting needs.

Common use cases include:

- Paid media budgets
- Revenue targets
- CPA and nCAC goals
- MER targets
- Order or acquisition targets
- Other client-specific KPIs

## **Where You Can Use Goals**

Once a Goal Metric has been created and target values have been entered, you can use it throughout SuperOrbital to monitor performance against plan.

- **Performance Reports** – Add goals alongside actual performance metrics to track pacing and view the percentage variance between actuals and targets.
- **Outlier Notifications** – Use goals to monitor performance and trigger automated Slack notifications when a metric is performing above or below its target.

## **How Goals Work**

Setting up a goal in SuperOrbital is a two-step process:

1. **Create the Goal Metric** – Define what you're tracking and tie the goal to the corresponding standard or custom metric in SuperOrbital.
2. **Enter Your Goal Values** – Add the daily target values you want SuperOrbital to use for comparison and pacing.

Once configured, SuperOrbital can compare the target values you provide against the actual performance data being pulled from your connected data sources.
