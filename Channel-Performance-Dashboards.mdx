## Overview

**Channel Performance Dashboards** provide a standardized view of performance for each paid media platform connected to SuperOrbital. A separate dashboard is available for each supported channel, allowing you to quickly review platform-level performance without building a custom report.

For example, if a client has Meta, Google Ads, TikTok, Bing, and Criteo connected, each platform will have its own Channel Performance Dashboard. While the data reflects the individual platform, the dashboard layout and functionality remain consistent across channels.

The **Date Range** and **Compare To** date range selections carry over from the Executive Summary Dashboard, making it easy to move between dashboards while maintaining the same reporting period.

> **Note:** Screenshots in this article may show a single paid media platform, but the same dashboard layout and functionality apply across supported channels.

## Filter Your Dashboard

Channel Performance Dashboards include additional filters that allow you to quickly narrow the data displayed across the entire page.

You can filter by:

- **Account** – Useful when a client has multiple ad accounts from the same platform connected to SuperOrbital.
- **Campaign Name** – Filter the dashboard to analyze performance for specific campaigns.

These filters apply to all scorecards, graphs, and tables on the page for quick, ad hoc analysis.

> **Note:** Dashboard filters are temporary and will not be saved after your active session. If you need to frequently report on the same subset of data, consider creating **Custom Metrics** or a **Custom Performance Report** using the appropriate filter criteria.

## Performance Scorecards

The scorecards at the top of each Channel Performance Dashboard provide a snapshot of the platform's primary performance KPIs.

Default metrics include:

- Spend
- Purchase Conversions
- Revenue / Purchase Conversion Value
- Cost per Purchase
- ROAS
- CPM
- Clicks
- CTR
- CPC

All data displayed in these scorecards is sourced directly from the corresponding paid media platform.

---

## Key KPIs

The **Key KPIs** graph allows you to visualize trends and plot the platform's primary performance metrics against one another.

Select the metrics you want to display on the graph. For the clearest visualization, we recommend plotting no more than two metrics at a time, as metrics with significantly different scales can make the graph more difficult to interpret when using shared axes.

Enable **Show Comparison** to visualize performance against your selected comparison period. You can adjust the **Compare To** date range using the date selector in the upper-right corner of the dashboard.

Use **Export** to download the graph as a JPEG or PNG for use in presentations, reporting decks, or other client materials.

---

## Performance by Day

The **Performance by Day** table provides a more detailed view of platform performance over time.

In addition to the primary KPIs displayed in the scorecards, this table includes additional metrics such as **Reach, Impressions, and CVR**.

Use the selector in the upper-right corner of the table to change the reporting rollup between:

- Day
- Week
- Month
- Year

When using longer rollups, make sure your dashboard date range includes the full period you want to analyze. For example, extend your date range to YTD when reviewing yearly performance.

---

## Campaign Performance

The **Campaign Performance** table provides the same core platform KPIs broken out by **Campaign Name** rather than by date.

Use this table to quickly compare campaign performance, identify top and bottom performers, and understand how individual campaigns are contributing to overall channel results.

> **Need a more granular performance breakdown?**
>
> For reporting beyond the Campaign level, use **Custom Performance Reports** to build tables using more granular dimensions such as **Ad Set/Ad Group, Ad Name/Creative, Audience Segment**, or other custom dimensions.
>
> You can also use Custom Performance Reports to create filtered views specific to your reporting needs, such as **Brand vs. Non-Brand performance**, Prospecting vs. Retargeting, or other custom campaign groupings.
